## 第二次（23:29 左右）—— 修 hal_gpio_port.c 的 gd32_gpio_init + 补全整条 GPIO 链路
- 用户问 `static uint8_t gd32_gpio_init(hal_gpio_t io, hal_gpio_mode_e mode)` 还需要什么、参数要不要改。
- 关键结论：**参数不用改**（`hal_gpio_mode_e` 已用组合语义隐含 speed/pull，够用）。
- 修掉的 bug：原代码 `rcu_idx = io % STRIDE`（实为引脚号）却拿去查 `s_port_rcu[]`（端口时钟表），
  且 `gpin = s_port_rcu[rcu_idx]` 也错。正确写法：`p_idx = io / STRIDE` 查表、`pin = io % STRIDE`、
  `gpin = 1UL << pin`（引脚掩码 = GPIO_PIN_x）。
- 补全了缺失的三块：`gd32_gpio_write/read/toggle` 三个 static 实现 + `s_gd32_gpio_ops` 表 +
  `hal_gd32f4_gpio_register()`（hal_port.c 里早就在调它但一直没定义）。
- 越界保护统一用 `p_idx >= sizeof(s_port_base)/sizeof(s_port_base[0])`。
- 编译验证：**0 Error, 0 Warning**，`Code=6718 RO-data=1618 RW-data=96 ZI-data=2176`。
- 记忆要点（给用户讲过的编码约定）：`hal_gpio_t = 端口索引*16 + 引脚号`；拆解口诀
  `io/16=端口`、`io%16=引脚`。

## 第三次（00:03 左右）—— 给 GPIO 加复用功能（AF，用户问「init 没考虑复用」）

    声明加 `hal_gpio_af_set()`。

  - `hal_gpio_port.c`：init 的 switch 加 `HAL_GPIO_MODE_AF` 分支；实现 `static uint8_t gd32_gpio_af_set()`
    （内部 `gpio_mode_set(GPIO_MODE_AF)` + `gpio_af_set(af)`）；注册进 ops 表。
- GD32 复用标准流程：`gpio_mode_set(...,GPIO_MODE_AF,...)` + `gpio_output_options_set(...)` + `gpio_af_set(port, af, pin)`。
